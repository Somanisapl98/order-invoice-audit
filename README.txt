1. Supabase SQL Editor: paste setup.sql and click Run.
2. Project Settings > API Keys: copy only the sb_publishable_ key. Never use sb_secret_.
3. Open config.js in Notepad and replace PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE.
4. Copy this folder to your OneDrive location.
5. Open CMD in this folder and publish to GitHub. See CMD_STEPS.txt.
6. New Updates shows records not yet audit-checked. Tick Audit, edit status/discount/comment, then Save.
